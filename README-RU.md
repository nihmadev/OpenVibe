OpenVibe — агентное окружение разработки с открытым исходным кодом, которое работает локально и построено на Tauri, Rust, React и Monaco. Оно объединяет AI-чат, редактирование кода, Git, терминал, языковые серверы, MCP-инструменты, исследования через подагента и изолированный браузер под управлением агента в одном лёгком desktop-приложении.

## Главное

- **Агентный процесс разработки** — потоковые рассуждения и действия инструментов, многошаговое выполнение, todo, rollback, проверяемые изменения файлов, статистика токенов, кеширование промптов и автоматическое сжатие контекста.
- **Автоматизация браузера** — изолированная сессия Chromium/CDP, в которой агент может переходить по страницам, анализировать их, кликать, вводить текст и делать снимки, а пользователь при необходимости может забрать ручное управление.
- **Полное рабочее пространство** — единый sidebar проектов и чатов, Monaco Editor и diff viewer, дерево файлов, ignore-aware поиск, Git status и граф коммитов, LSP и многовкладочный терминал xterm.js.
- **Расширяемые инструменты** — встроенные инструменты файловой системы, shell, Git, web, browser, todo, skills и research-подагента плюс динамически обнаруживаемые MCP-инструменты.
- **Свобода выбора провайдера** — встроенный обновляемый каталог `models.dev`, готовые шаблоны популярных сервисов, пользовательские OpenAI-совместимые endpoint и локальные модели через Ollama, LM Studio или vLLM.
- **Глубокая кастомизация** — 40 встроенных тем, отдельные светлая/тёмная палитры, import/export тем, 38 выбираемых языков интерфейса, ленивая загрузка UI/code-шрифтов, настройка оформления, zoom и анимаций.

## Возможности продукта

### Агент, контекст и проверка изменений

Агент использует нативный инкрементальный SSE-пайплайн для провайдеров форматов OpenAI и Anthropic. Ответ, рассуждения, аргументы инструментов, usage, статистика кеша, время до первого токена и скорость передаются структурированными событиями и отображаются единым линейным потоком активности.

- Сжатие с учётом токенов сохраняет исходную задачу, последние шаги, состояние инструментов и snapshot файлов, сокращая старую часть диалога.
- Стабильные ключи prompt cache и движущиеся точки кеширования уменьшают повторную обработку входных данных у поддерживаемых провайдеров и proxy.
- Сфокусированные профили инструментов уменьшают промпт: схемы Git, web, research, browser и отдельных MCP-серверов загружаются только после запроса или использования.
- Успешные изменения агента сохраняют snapshot до/после и могут быть просмотрены, приняты, отклонены или безопасно восстановлены через Monaco diff.
- `@`-упоминания файлов, изображения и документы добавляют явный контекст, а inline-превью сохраняют его видимым в истории.
- Настраиваемые режимы разрешений управляют доступом к shell, файловой системе, браузеру и другим чувствительным возможностям.

### Встроенный браузер

OpenVibe запускает автоматизацию в изолированном Chromium-процессе через Chrome DevTools Protocol. Панель Browser содержит адресную строку, навигацию, несколько вкладок, живые кадры страницы, визуализацию указателя агента и ручное управление. Browser-инструменты поддерживают навигацию, accessibility snapshot, клики, ввод текста, клавиатуру, hover, прокрутку, историю, вкладки, screenshot и ожидание. Политика навигации блокирует привилегированные и локальные URL-схемы до передачи в Chromium.

### Workspace, редактор, Git и поиск

- Единый sidebar объединяет проекты с раскрываемыми чатами, закреплённые и недавние диалоги, поиск и действия над проектами/чатами.
- Monaco предоставляет многовкладочное редактирование, кешируемые модели документов, просмотр кода и diff, подсветку синтаксиса, настраиваемую типографику и просмотр изображений/видео.
- Source Control поддерживает staged/unstaged-группы, действия над файлами, переключение веток, diff, создание коммитов, историю и визуальный граф коммитов.
- Поиск исходников и файловые инструменты агента используют общие ограниченные, ignore-aware обход файлов и политику путей.
- Легковесное дерево проекта в реальном времени передаёт агенту структуру репозитория без прежнего стека AST- и векторной индексации.

### MCP, LSP и терминал

- Локальные MCP-серверы работают через stdio/JSON-RPC 2.0; обнаруженные инструменты регистрируются как `mcp__<server>__<tool>` и отображаются в live-настройках и статусах.
- Поддержка Language Server Protocol управляет установкой серверов, процессами и подключением редактора для распространённых языков разработки.
- Встроенный xterm.js поддерживает несколько нативных PTY-сессий, определение shell, изменение размера и потоковый вывод в реальном времени.

### Провайдеры и персонализация

OpenVibe поставляется со snapshot каталога провайдеров/моделей `models.dev`, загружает его лениво, кеширует обновления локально и обновляет в фоне. Для Anthropic, OpenAI, Google Gemini, DeepSeek, Groq, OpenRouter, Ollama, Mistral, xAI, AWS Bedrock, Azure OpenAI, GitHub Models и многих других сервисов доступны готовые шаблоны. Пользовательские провайдеры поддерживают произвольные base URL, headers, keys, model ID и параметры.

Интерфейс на базе Zazaru включает 40 встроенных тем, редактируемые светлую и тёмную схемы, выбор UI- и code-шрифтов, границы, радиусы, tabs, blur, zoom, управление анимациями, модульную систему иконок и 38 выбираемых языков.

## Архитектура

OpenVibe состоит из трёх runtime-областей:

- React/TypeScript-рендерер в `src/`, разделённый на упорядоченные по зависимостям слои `base`, `platform` и `workbench`;
- Tauri-хост в `src-tauri/`, который предоставляет тонкие команды и владеет долгоживущими runtime-менеджерами;
- специализированные Rust-сервисы в `crates/`, соединённые явными контрактами и event sinks.

16 Rust-крейтов:

- **`agent-api`** — общие сообщения, события, snapshot, определения инструментов и контракты executor.
- **`llm`** — запросы провайдеров, преобразования, отмена, учёт токенов и SSE-декодирование.
- **`agent`** — оркестрация, промпты, compaction, rollback, snapshot, summary и профили инструментов.
- **`agent-tool`** — инструменты файловой системы, shell, Git, поиска, MCP, браузера, web, todo, skills и подагента.
- **`browser`** — установка и жизненный цикл изолированного Chromium, CDP, навигация, ввод, snapshot, вкладки и screencast.
- **`fs`** — общая политика путей, ignore-правила, ограниченное чтение текста и обход файловой системы.
- **`runtime`** — установка и управление загружаемыми языковыми runtime.
- **`search`** — кешируемый ограниченный поиск исходников на общем файловом слое.
- **`lsp`** — процессы языковых серверов и управление протоколом.
- **`mcp`** — жизненный цикл MCP-процессов, JSON-RPC transport, обнаружение и выполнение инструментов.
- **`git`** — операции с репозиторием через libgit2.
- **`db`** — хранение проектов и состояния приложения в bundled SQLite.
- **`chats`** — хранение и сериализация диалогов.
- **`terminal`** — жизненный цикл и стриминг терминальных процессов.
- **`editor`** — состояние документов и файловые операции редактора.
- **`config`** — типы конфигурации приложения и провайдеров.

Дополнительный Go-сервис в `api/` проксирует запросы к провайдерам, прогревает соединения, управляет таймаутами и health checks и поддерживает проверку обновлений. Полные правила зависимостей, runtime-границы и потоки состояния/событий описаны в [docs/architecture.md](docs/architecture.md).

## Разработка

### Требования

- Node.js `>= 18`
- Стабильный Rust toolchain (`cargo`, `rustc`)
- Linux, macOS или Windows

Browser-функция использует установленный Chrome/Chromium, если он доступен, и при необходимости может загрузить управляемый Chromium runtime.

### Установка и запуск

```bash
git clone https://github.com/nihmadev/OpenVibe.git
cd OpenVibe
npm install
npm run dev
```

`npm install` также копирует runtime-assets Monaco из установленного пакета. `npm run dev` запускает Vite-рендерер и desktop-хост Tauri.

### Сборка и проверка

```bash
npm run build              # Сборка renderer и нативного Tauri-приложения
npm run check              # Архитектура, TypeScript, ESLint и Biome
npm test                   # Frontend unit/integration тесты через Vitest
cargo test --workspace     # Тесты Rust workspace
```
